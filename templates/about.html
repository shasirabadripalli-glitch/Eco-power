EcoPower - Smart India Hackathon 2026

Official Project Proposal & Evaluation Brief for Problem Statement SIH26217

Project Details

  • Problem Statement: Student Innovation – Innovative ideas that help manage and generate renewable / sustainable sources more efficiently.
  • Organization: AICTE (All India Council for Technical Education)
  • Category: Hardware Prototype
  • Theme: Renewable / Sustainable Energy
  • Target Deadline: 20 September 2026

The Core Innovation

While solar panel deployment is accelerating across India, traditional microgrid installations lack intelligent load balancing. When irradiance drops or battery reserves fall, system failures occur or expensive grid electricity is drawn blindly.

EcoPower solves this via Smart Energy Management: An automated rule-based load shedding algorithm running on an ESP32 hardware node and Python Flask backend. It prioritizes essential loads (e.g. medical, emergency lighting, security), controls secondary loads (fans/cooling), and sheds heavy non-essential loads (EV chargers/water heaters) during power deficits.

SIH Evaluation Criteria Mapping

1. Novelty & Innovation

Dynamic priority-based load management combined with real-time tariff and carbon offset tracking.

2. Technical Feasibility

Built using low-cost ESP32, INA219 power sensor, relay switches, Python Flask, and simple CSV/JSON storage.

3. Social & Environmental Impact

Prevents battery deep-discharge damage, increases clean energy self-consumption percentage, and reduces grid carbon emissions.

4. Scalability

Easily adaptable for residential homes, educational campuses, remote agricultural solar pumps, and commercial microgrids.
